# هم‌ورق (hamvaraq)

سایت مبادله‌ی رایگان کتاب: کتاب بده، ۱ امتیاز بگیر؛ با امتیاز کتاب بگیر. Django + SQLite.

## اجرا

```bash
python -m venv .venv && source .venv/bin/activate   # ویندوز: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env
python manage.py migrate
python manage.py seed_basics        # شهرها و دسته‌ها
python manage.py createsuperuser
python manage.py runserver
python manage.py test
```

## داکر

```bash
cp .env.example .env
docker compose up --build            # توسعه: http://localhost:8000 با پستگرس
```

پروداکشن (`.env` با `SECRET_KEY`، `ALLOWED_HOSTS`، `CSRF_TRUSTED_ORIGINS` و `DB_PASSWORD` واقعی):

```bash
docker compose -f docker-compose.prod.yml up -d --build
```
nginx روی سرور با `deploy/hamvaraq.nginx.conf.example` جلوی پورت `127.0.0.1:8000` قرار می‌گیره.
`python manage.py createsuperuser` رو داخل کانتینر `web` اجرا کن.

## ساختار

| اپ | کار |
|---|---|
| `accounts` | کاربر (امتیاز، وضعیت، محدودیت)، نشان‌ها، ثبت‌نام/ورود/بازیابی رمز |
| `books` | کتاب، جستجو، لیست آرزو، یادداشت داخل کتاب، مسیر کتاب |
| `exchanges` | درخواست ← تأیید ← تحویل ← تأیید دوطرفه، چت (منطق در `services.py`) |
| `trust` | لایک/دیسلایک، اعتبار، گزارش و تصمیم ادمین |
| `notifications` | اعلان داخل سایت |

## قوانین امتیاز
- کاربر جدید امتیاز صفر دارد؛ با تکمیل اولین مبادله‌ی «دادن» ۱ امتیاز می‌گیرد.
- هنگام درخواست ۱ امتیاز نگه داشته می‌شود؛ با رد/لغو برمی‌گردد و با تکمیل مبادله خرج می‌شود.
- با تأیید یک درخواست، بقیه‌ی درخواست‌های همان کتاب رد و امتیازشان برگردانده می‌شود.
- پس از مبادله کتاب به گیرنده منتقل می‌شود (وضعیت «مبادله‌شده») و او می‌تواند دوباره آن را برای مبادله بگذارد.

## اعتماد و ایمنی
- رأی فقط بعد از مبادله‌ی کامل‌شده، یکی از هر طرف، قابل ویرایش تا ۲۴ ساعت.
- رأی‌های بین دو نفری که بیش از ۲ مبادله با هم داشته‌اند وزن نصف می‌گیرد.
- زیر ۶۰٪ با حداقل ۵ رأی: «اعتبار پایین». بدون رأی: «تازه‌وارد».
- گزارش روی کاربر/کتاب/پیام؛ هر کاربر یک‌بار برای هر مورد. ادمین در `/admin/` تصمیم و دلیل را ثبت می‌کند
  (رد، اخطار، محدودیت، مسدودسازی). ۳ گزارش تأییدشده‌ی بدقولی ← محدودیت خودکار.
- تنظیمات عددی در `HamVaraqDjangoServer/settings.py` (بخش «قوانین دامنه»).

## نسخه‌ی ۲ (انجام‌شده)
- صفحه‌ی شهر با آمار (`/cities/`) و تازه‌رسیده‌ها.
- ثبت دسته‌ای (`/books/bulk/`) و پر کردن خودکار با شابک از Open Library (کتاب‌های فارسی ممکنه پیدا نشن؛ دستی پر کن).

- نقد و ستاره: فقط گیرنده‌ی کتاب در مبادله‌ی کامل‌شده، یک نقد قابل ویرایش برای هر کتاب.
- قفسه‌ی مجازی: پروفایل کتاب‌ها رو روی قفسه نشون می‌ده (به‌جز رزروها).
- چالش‌های فصلی: از `/admin/` چالش بساز (نوع، هدف، بازه)؛ پیشرفت از مبادله‌های کامل‌شده حساب می‌شه و رسیدن به هدف نشان می‌ده.
